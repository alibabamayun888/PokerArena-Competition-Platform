**PokerArena Competition Platform** 是一套面向德州撲克 SNG、MTT、競技排名賽和線上線下賽事串接的比賽平台。系統採用 **Unity3D 跨平台客戶端、C++ 即時遊戲伺服器和 Java 營運管理後台**，涵蓋賽事報名、身分認證、牌桌競技、盲注升級、淘汰晉級、即時排名、獎勵結算與線下比賽門票兌換流程。

專案適用於德州撲克賽事平台開發、多人即時競技遊戲研究、線上資格賽、線下比賽報名和賽事營運系統整合。儲存庫頁面展示產品與技術方案；實際部署前請依程式碼版本核對模組、相依套件與合規要求。

## 專案概述

PokerArena 將線上德州撲克比賽、錦標賽排程、參賽資格、實名與人臉認證、積分排名和線下比賽門票管理整合到統一流程中。

```text
賽事發布 → 玩家報名 → 身分與資格檢查 → 開賽與分桌
        → 盲注升級 → 淘汰與併桌 → 決賽桌與結算
        → 排名/積分/門票發放 → 線下賽事核銷
```

| 層級 | 技術 | 主要職責 |
| --- | --- | --- |
| 客戶端 | Unity3D 2021.3 LTS | iOS / Android 介面、賽事大廳、報名、牌桌與結果顯示 |
| 客戶端通訊 | WebSocket | 即時訊息、心跳、斷線重連與狀態恢復 |
| 遊戲伺服器 | C++17 / Boost.Asio | 牌局狀態、玩家行動、賽事排程與即時同步 |
| 業務後台 | Java 17 / Spring Boot 3.x | 賽事設定、使用者審核、門票、營運與風控管理 |
| 資料服務 | MySQL 8.0 / Redis 7.x | 持久化資料、快取、線上狀態與排行榜 |
| 身分認證 | 第三方實名與人臉辨識服務 | 活體檢測、身分核驗與參賽資格確認 |

## 賽事模式

### MTT 多桌錦標賽

- 多桌同時開賽，依賽事進度動態拆桌和併桌。
- 支援盲注等級、前注、延遲報名、重購和加購設定。
- 記錄淘汰順序、即時排名、獎勵名次和決賽桌結果。

### SNG 單桌快速賽

- 達到預設人數後自動開賽。
- 適合單桌快速競技、日常賽和固定人數資格賽。
- 可設定參賽條件、起始籌碼、盲注速度和獎勵名次。

### 競技排名賽

- 支援賽事積分、週期排行榜和賽季晉級規則。
- 可將線上比賽成績與線下賽事參賽資格關聯。
- 適用於系列賽、資格賽和品牌賽事營運。

## 系統架構

```text
┌─────────────────────────────────────────────┐
│                Unity3D 客戶端               │
│  賽事大廳 · 報名 · 牌桌 · 排名 · 門票中心   │
└────────────────────┬────────────────────────┘
                     │ WebSocket / API
┌────────────────────▼────────────────────────┐
│                C++ 遊戲伺服器               │
│  牌局狀態 · 發牌 · 行動驗證 · 賽事排程 · 結算│

                     │ 內部服務介面 / 事件
┌────────────────────▼────────────────────────┐
│                 Java 管理後台               │
│  賽事設定 · 使用者審核 · 排名 · 門票 · 風控  │
└────────────────────┬────────────────────────┘
                     │
┌────────────────────▼────────────────────────┐
```

客戶端負責顯示和互動，關鍵牌局狀態、隨機數、行動合法性與比賽結果必須由伺服器權威計算。管理後台不直接參與即時發牌，而是透過受控介面管理賽事與營運資料。

## 客戶端

Unity3D 客戶端面向 iOS 與 Android，提供賽事大廳、比賽詳情、報名候場、即時牌桌、排名結果、個人中心、資格卡、門票狀態、斷線重連和多語言擴充。

## 遊戲伺服器

C++ 遊戲伺服器負責德州撲克狀態機、合法行動驗證、服務端發牌、底池與邊池、連線管理、SNG/MTT 生命週期、盲注升級、拆併桌、淘汰、晉級和結算事件。

並行容量與延遲必須以實際程式碼版本、硬體、編譯參數和壓測報告為準。本 README 不提供未經公開基準測試驗證的固定效能承諾。

## 身分認證與安全

平台可在帳號認證、重要賽事報名、門票領取和現場核銷等節點串接實名與人臉辨識服務。

- 採集前應說明用途並取得使用者單獨同意。
- 人臉圖像和生物特徵應依敏感個人資料實施加密與存取控制。
- C++ 遊戲伺服器只讀取最小化認證狀態，不保存人臉原始圖像。
- 提供保存期限、撤回授權、刪除和人工複核流程。
- 對管理、認證、報名和領獎介面實施鑑權、限流與稽核。

## 線上與線下賽事門票

1. 玩家參加線上 SNG、MTT 或積分賽並取得排名或資格。
2. 系統依活動規則發放比賽卡或線下門票。
3. 玩家在客戶端查看和領取資格。
4. 後台完成實名資訊與參賽條件審核。
5. 線下現場透過安全憑證或 QR Code 核銷。
6. 核銷結果回寫後台並形成稽核記錄。

## 常見問題

### PokerArena 支援哪些比賽？

專案定位涵蓋 SNG、MTT、競技排名賽、線上資格賽和線下比賽門票串接。

### 使用哪些技術？

客戶端使用 Unity3D，即時遊戲伺服器使用 C++，賽事營運後台使用 Java / Spring Boot。

### 是否支援 iOS 和 Android？

線上專案說明定位於 iOS 與 Android。實際可建置平台和最低版本應以目前 Unity 工程設定及測試結果為準。

### 人臉辨識是否必須啟用？

不一定。應依比賽規則與所在地法規決定；啟用時必須提供隱私說明、明確同意和資料刪除機制。

### 可以直接用於商業營運嗎？

能否商用取決於程式碼完整度、授權條款、第三方 SDK、安全測試和當地法律。上線前應完成程式碼稽核、壓力測試、隱私評估和法律審查。
