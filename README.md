## 🎯 项目概述

**PokerArena** 致力于为开发者提供一套可直接用于商业运营的**德州扑克锦标赛系统源码**。区别于普通娱乐型棋牌项目，本系统专为**竞技赛事场景**设计，深度还原线下专业扑克比赛的完整生命周期：

报名注册 → 实名认证 → 入座开赛 → 盲注增长 → 淘汰晋级 → 决赛桌 → 奖励结算 → 门票发放

无论你是希望搭建类似 CPG、TJPT 等**线下德州比赛**的线上报名与门票系统，还是想运营一个纯线上的**德扑竞技平台**，本框架都能提供稳定可靠的基础支撑。

### 为什么选择 PokerArena？

| 维度 | 传统方案 | PokerArena |
|------|----------|------------|
| 赛事模式 | 仅支持单桌 | MTT + SNG + 排名赛 全支持 |
| 认证方式 | 手机号/昵称 | **人脸识别** + 实名双因子认证 |
| 门票体系 | 无 | **线上积分兑换线下赛事门票** |
| 技术栈 | 单一语言 | Unity + C++ + Java 分离架构 |
| 生产就绪 | Demo 级别 | **真实运营验证**的完整源码 |

## 🎮 核心功能

### 1. 多模式赛事系统
- **MTT 多桌锦标赛 (Multi-Table Tournament)**：支持千人级同时参赛，自动拆桌合桌，动态平衡座位。
- **SNG 单桌快速赛 (Sit & Go)**：满员即开，快速决出冠军，适合碎片化时间竞技。
- **排名积分赛**：周期性积分排名，支持赛季制与段位晋升体系。

### 2. 专业盲注引擎
- 可配置盲注增长曲线（线性、指数、自定义）。
- 支持前注 (Ante)、延迟报名 (Late Registration)、重购 (Rebuy)、加购 (Add-on)。
- 决赛桌自动触发暂停与座位调整。

### 3. 智能奖池分配
- 内置 ICM (Independent Chip Model) 与线性分配双算法。
- 支持固定奖池、保底奖池 (Guaranteed Prize Pool) 与赏金赛 (Bounty)。
- 自动扣税计算与多币种支持。

### 4. 实时数据看板
- 玩家实时排名与筹码量同步。
- 决赛桌直播数据推送。
- 历史牌谱回放与手牌分析 (Hand History)。

## 📱 客户端特性

- **跨平台双端**：一套 Unity 代码编译 iOS / Android，支持热更新 (HybridCLR / Lua)。
- **竞技级 UI**：专业牌桌视角、筹码飞行动画、表情互动、聊天气泡。
- **低延迟同步**：基于 C++ 服务端的 200ms 级状态同步，操作即时响应。
- **多语言支持**：中文、英文一键切换，可扩展更多语种。
- **离线重连**：网络波动时自动恢复牌局状态，不掉线、不丢包。

## ⚡ 服务端特性

- **C++ 核心服务**：单节点支持 10,000+ 并发牌桌，CPU 占用低于 30%。
- **状态机驱动**：严谨的德州扑克状态机，覆盖所有边界场景（All-in、边池、死钱等）。
- **防作弊体系**：牌局加密传输、服务端发牌、客户端零信任验证。
- **水平扩展**：基于 Redis 的分布式房间管理，支持无状态扩容。

## 🔐 安全与认证

- **人脸识别实名认证**：集成主流 AI 人脸识别 SDK，完成活体检测 + 身份证 OCR + 人脸比对，确保参赛选手身份真实。
- **设备指纹**：绑定设备 ID，防止多开与模拟器。
- **行为风控**：基于大数据模型识别机器人、伙牌、异常弃牌等行为。
- **通信加密**：全链路 TLS 1.3 + 自定义二进制协议加密。

📊 赛事系统详解

MTT 锦标赛生命周期
[赛前] 创建赛事 → 配置盲注结构 → 设置奖池分配 → 开放报名
   ↓
[赛中] 玩家入座 → 发牌 → 盲注增长 → 拆桌/合桌 → 泡沫期 → 决赛桌
   ↓
[赛后] 排名锁定 → 奖池分配 → 门票/积分发放 → 数据归档


SNG 快速赛流程

选择买入级别 (Buy-in)
满员自动开赛 (通常 6/9 人桌)
快节奏盲注增长 (3-5 分钟/级别)
决出前三名，即时发放奖励


🏆 线上线下门票联动

本系统创新性地打通了线上竞技积分与线下赛事门票的兑换体系：
积分累积：参与线上 MTT / SNG 获得排名积分 (Rank Points)。
门票兑换：积分可在商城兑换线下大型赛事 (如 CPG、TJPT 风格) 的参赛门票。
电子票务：生成加密二维码电子票，现场扫码核销入场。
酒店/专车预约：可选模块，为线下参赛玩家提供一站式行程服务。

❓ 常见问题

Q: 本项目是否可以直接用于商业运营？
A: 是的。PokerArena 基于 MIT 协议开源，代码经过真实生产环境验证，但请确保你的运营符合当地法律法规。
Q: 支持哪些第三方人脸识别服务？
A: 目前预留了阿里云、腾讯云、虹软 (ArcSoft) 的 SDK 接入接口，可根据需求选择。
Q: 是否支持网页版 (H5/WebGL)？
A: 当前版本专注 iOS/Android 原生性能体验。WebGL 版本已在 Roadmap 中，预计下一版本提供。
Q: 最大支持多少玩家同时在线？
A: 单台 C++ 核心服务节点可稳定支撑 10,000 桌并发，通过 Kubernetes 水平扩展可支持百万级并发。
Q: 如何防止玩家伙牌 (Collusion)？
A: 系统内置风控引擎，实时分析下注模式、IP 关联、设备指纹等 20+ 维度指标，异常行为自动标记并上报。
